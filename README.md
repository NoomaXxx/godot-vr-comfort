# Limn Comfort Layer — Godot 4.x Plugin

Automatic VR comfort features for Godot 4.x.
No manual setup needed — add the plugin, it works.

## Features (planned)
- Auto-Vignette (reduces motion sickness)
- Snap-Turn
- Teleport locomotion
- IPD calibration

## Status
🚧 Early development — Phase 0

## Installation
1. Download the `addons/vr_comfort` folder
2. Copy into your Godot project
3. Enable in Project → Plugins
